==============================================================================
简介							*previm-introduction*

本插件提供在浏览器中预览文件的功能，可实现近乎实时的预览效果。

[支持的格式]
	- Markdown
	- textile
	- reStructuredText (需要 rst2html.py)

最新版本:
http://github.com/previm/previm


==============================================================================
依赖							*previm-depends*

[必需]
	无

[可选]
	- open-browser.vim (https://github.com/tyru/open-browser.vim)


==============================================================================
使用方法						*previm-usage*

以下以 Markdown 为例说明，其他格式的基本操作相同。

1. 在 .vimrc 中设置 |g:previm_open_cmd|。如果使用 open-browser.vim 则无需设置。
2. 开始编辑 |filetype| 为 Markdown 的文件。
3. 使用 |:PrevimOpen| 在浏览器中打开预览。
4. 返回缓冲区继续编辑。
5. 每次更新时，更改会自动反映到浏览器页面上。

==============================================================================
命令							*previm-command*

							*:PrevimOpen*
:PrevimOpen
	在浏览器中打开当前文件的预览。


==============================================================================
函数							*previm-functions*

previm#open({path})					*previm#open()*
	将 {path} 设置为要在浏览器中打开的 URL。

previm#refresh()					*previm#refresh()*
	应用对文件所做的更改。这将自动更新浏览器中显示的页面。


==============================================================================
设置							*previm-settings*


g:previm_open_cmd					*g:previm_open_cmd*
	类型: String

	指定 |:PrevimOpen| 执行的命令。如果未指定，则执行 openbrowser#open。
	另请参阅 |previm-openbrowser|。

	以下示例配置在 Mac 上使用 Firefox 或 Google Chrome 打开。
>
	" .vimrc
        " 使用 Firefox 打开
	let g:previm_open_cmd = 'open -a Firefox'

        " 使用 Google Chrome 打开
        let g:previm_open_cmd = 'open -a Google\ Chrome'
<

g:previm_enable_realtime			*g:previm_enable_realtime*
	类型: Num

	选择是否实时预览更改。
	如果值为 0，则仅在以下时机反映更改:

	  * 保存文件时

	如果值为 1，则可以近乎实时地预览。
	默认值为 0。

	如果在打开预览文件后更改此值，需要重新打开预览文件才能使设置生效。
>
	" .vimrc
	" 实时预览
	let g:previm_enable_realtime = 1

g:previm_disable_default_css			*g:previm_disable_default_css*
	类型: Num

	预览时不应用默认 CSS。
	只有值为 1 时有效，其他值将被忽略。

>
	" .vimrc
	" 禁用默认 CSS
	let g:previm_disable_default_css = 1

g:previm_custom_css_path			*g:previm_custom_css_path*
	类型: String

	预览时可以添加自定义 CSS。
	此 CSS 将在默认 CSS 之后加载。
	请将 CSS 文件的绝对路径写入设置值。

>
	" .vimrc
	" 在默认 CSS 基础上应用自定义 CSS
	let g:previm_custom_css_path = '/Users/kanno/tmp/some.css'

	" .vimrc
	" 不使用默认 CSS，仅应用自定义 CSS
	let g:previm_disable_default_css = 1
	let g:previm_custom_css_path = '/Users/kanno/tmp/some.css'

g:previm_show_header					*g:previm_show_header*
	类型: Num

	如果值为 1，预览时将显示页眉。
	页眉显示正在编辑的文件名和更新时间。

	如果值为 0，预览时不显示页眉。
	默认值为 1。

>
	" .vimrc
	let g:previm_show_header = 0


g:previm_plantuml_imageprefix			*g:previm_plantuml_imageprefix*
	类型: String

	如果要在本地使用 PlantUML 服务器，请指定其端点。

	如果未指定，则使用 http://plantuml.com/plantuml/img/。

>
	" .vimrc
	let g:previm_plantuml_imageprefix = 'http://localhost:8888/plantuml/img'


==============================================================================
与 OPEN-BROWSER.VIM 配合使用				*previm-openbrowser*

选择显示预览的浏览器时，按以下步骤进行:

1. 尝试执行 |g:previm_open_cmd| 中设置的命令
  - 如果 |g:previm_open_cmd| 未定义或为空，则进入步骤 2
2. 尝试使用 openbrowser#open() 打开浏览器
  - 如果未安装 open-browser.vim，则进入步骤 3
3. 显示无法找到可执行命令的错误信息后退出

因此，使用 open-browser.vim 时无需配置 |g:previm_open_cmd|。
